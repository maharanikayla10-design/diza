DailyBoard

DailyBoard adalah aplikasi sederhana untuk membantu pengguna mengatur tugas,
membuat catatan, melihat kutipan harian, dan melihat informasi cuaca.

Fitur

DailyBoard memiliki beberapa fitur:

- Menambahkan tugas
- Menghapus tugas
- Mengedit tugas
- Menandai tugas sebagai selesai
- Mencoret tugas
- Filter tugas:
  - Semua
  - Selesai
  - Belum Selesai
- Drag and Drop untuk mengubah urutan tugas
- Pencarian tugas
- Debounce pada pencarian
- Menambahkan catatan
- Mengedit catatan
- Menghapus catatan
- Penyimpanan data menggunakan LocalStorage
- Kutipan hari ini menggunakan API
- Informasi cuaca berdasarkan kota
- Dark Mode
- Tampilan responsive untuk laptop dan perangkat mobile

Cara Menggunakan

1. Menambahkan tugas

Masukkan tugas pada kolom input, kemudian klik tombol
"Tambah".

2. Menyelesaikan tugas

Klik tombol "Selesai" pada tugas yang ingin diselesaikan.

3. Mengedit tugas

Klik dua kali pada nama tugas untuk mengubahnya.

4. Menghapus tugas

Klik tombol "Hapus" pada tugas yang ingin dihapus.

5. Mencari tugas

Masukkan kata yang ingin dicari pada kolom
"Cari tugas".

6. Menggunakan filter

Gunakan tombol:

- Semua
- Selesai
- Belum Selesai

untuk menampilkan tugas berdasarkan statusnya.

7. Catatan

Masukkan catatan pada kolom catatan kemudian klik
"Tambah Catatan".

Catatan dapat diedit dan dihapus.

8. Cuaca

Masukkan nama kota kemudian klik tombol
"Cek Cuaca" untuk melihat informasi cuaca.

9. Dark Mode

Klik tombol "Mode Gelap" pada bagian header untuk
mengubah tampilan menjadi dark mode.
